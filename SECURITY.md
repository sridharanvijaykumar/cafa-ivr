# Security

CAFA-IVR is a testing framework and may be integrated with production voice/contact-center systems.

Do not commit credentials, customer audio, authentication data, account identifiers, API keys, or proprietary transcripts to this repository.

Use synthetic or appropriately licensed/public test data in examples. Organizations integrating CAFA-IVR with real systems should use their normal secrets manager, access controls, retention policies, and data-governance requirements.

For a security issue in the reference implementation, open a GitHub security advisory after the repository is published rather than posting sensitive exploit details in a public issue.
